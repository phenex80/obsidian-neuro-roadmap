# Changelog

All notable changes to Neuro Roadmap are documented here.

## 0.1.1 - 2026-08-16

### Fixed

- Made the Google OAuth loopback server mobile-safe while preserving the working desktop OAuth flow.
- Resolved Obsidian Community review warnings related to type safety, method binding, DOM creation, error handling, regexes, and task metadata styling.
- Replaced the native browser confirmation dialog with an Obsidian-native confirmation modal.
- Improved compatibility with Obsidian popout windows.

### Changed

- Updated destructive-button handling with compatibility fallbacks for Obsidian 1.11–1.12.
- Preserved legacy settings rendering to maintain compatibility with Obsidian 1.11.4 and later.


## Unreleased

### Added

- Publication metadata, PolyForm Noncommercial licensing, privacy documentation, BRAT guidance, and a release checklist.
- Optional user-initiated Revolut and Ko-fi support links in plugin settings.
