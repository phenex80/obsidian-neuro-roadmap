# Contributing to Neuro Roadmap

Bug reports, feature requests, documentation suggestions, and respectful discussions are welcome through the project's issue tracker.

## Code contributions

For now, substantive third-party code contributions are accepted only by prior agreement with the maintainer. Before any such work is merged, its licensing and possible relicensing terms must be clarified in writing. Opening a pull request does not automatically mean that it will be accepted or merged.

This project does not currently use a contributor license agreement or copyright-assignment process. A formal CLA or relicensing process may be introduced later if the project begins accepting substantial external code contributions.
