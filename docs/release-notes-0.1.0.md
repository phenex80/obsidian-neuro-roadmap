# Neuro Roadmap 0.1.0

Neuro Roadmap 0.1.0 is the first public beta release of a Markdown-backed academic planning layer for Obsidian.

## Highlights

- Dashboard overview for subjects, task completion, deadlines, overdue work, and mini timelines.
- Hierarchical Gantt view with semantic Fit, Weeks, Months, and Semester scales, Today Line, overview ribbon, and priority markers.
- Horizon view with Now, Next, Later, and Unscheduled work.
- Normal Markdown checkbox tasks with semantic property mapping for existing vault schemas.
- Compact task metadata and Task Properties editing in Live Preview.
- Local ICS export.
- Optional one-way Google Calendar projection on Obsidian desktop.

Markdown remains the source of truth. Google Calendar direct connection is desktop-only, and Google edits are not imported back into Markdown. Generic ICS export remains available independently.
